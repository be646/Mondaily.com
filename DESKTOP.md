# Mondaily Desktop

This folder is ready to run as an Electron desktop app.

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the desktop app:
   ```bash
   npm start
   ```

3. Build a desktop app package:
   ```bash
   npm run package:mac
   ```

   or for Windows:
   ```bash
   npm run package:win
   ```

The app keeps account data locally in browser storage inside the desktop app.
